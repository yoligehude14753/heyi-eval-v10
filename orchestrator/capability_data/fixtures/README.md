## Layout

```
fixtures/
  images/
    vision/  → 10 PNGs (solid colors, shape grids)
    ocr/     → 10 PNGs (bitmap-rendered text "2026", "STOP", "GO LEFT" ...)
    provenance.txt (one per subdir)
  audio/
    *.wav (synthetic sine tones; placeholder for music_understanding)
    provenance.txt
  videos/
    provenance.txt (currently empty; see note)
```

## Licensing rule (hard constraint)

**Every fixture file MUST be CC0 / public domain / unambiguous redistribution rights.**

* Synthetic fixtures (everything PR#16 ships) are generated by
  `scripts/build_capability_fixtures.py` and are released CC0 by us.
* Future real-content additions (e.g. LibriSpeech clips) must have a
  per-file row in the relevant `provenance.txt`. Files without a
  provenance entry are dropped at fixture-loader time.

## Regenerating

```bash
# from repo root, after editing scripts/build_capability_fixtures.py:
python scripts/build_capability_fixtures.py --clean
```

The script is deterministic — byte-identical output each run.

## Size budget

The entire fixtures/ tree should stay under 20 MB. Current PR#16 footprint: ~230 KiB.
